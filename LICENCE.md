## ✨ Features

### ESP
- Entity Viewer — highlight mobs and players for study
- Coordinate Display — show current position and orientation
- Block Info — inspect block types and properties
- Game Speed — adjust simulation speed for testing (0.1x to 5x)

### Wallhack
- Inventory Viewer — browse and manage inventory contents
- Item Catalog — list all items with metadata
- Skin Notes — organize player cosmetics

### Aimbot
- Chunk Borders — visualize chunk boundaries
- Light Level Overlay — show light levels for building
- Biome Map — display biome distribution
- Waypoint Notes — mark points of interest
